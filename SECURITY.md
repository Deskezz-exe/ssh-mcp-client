# Security Policy

Это личный desktop-инструмент, но раз код открыт, вот что реально защищено и как.

## Что защищено

- **Пароли от серверов** никогда не попадают на диск в открытом виде — только в системное хранилище учётных данных ОС (`keyring`). Не логируются, не отдаются фронтенду, не хранятся в `servers.json`.
- **SSH host key** проверяется по модели trust-on-first-use: отпечаток сервера запоминается при первом подключении и сверяется на каждом следующем — при расхождении соединение обрывается.
- **Команды через MCP**: разрушительные по паттерну команды (`rm -rf`, `dd`, `mkfs`, `shutdown` и т.п.) не выполняются сразу, а требуют явного подтверждения через отдельный вызов с одноразовым токеном. Полный список см. в `src-tauri/src/audit/dangerous.rs`.
- **Удаление файлов** через MCP не доступно вообще — только руками через GUI.
- **MCP-сервер** слушает только `127.0.0.1`, наружу не торчит.
- Каждый вызов MCP пишется в локальный аудит-лог (SQLite).

Подробнее — в разделе Security в [README.md](README.md).

## Что не защищено (осознанно, вне рамок MVP)

- MCP-эндпоинт не требует аутентификации — предполагается, что к `127.0.0.1:47821` на этой машине имеет доступ только сам пользователь.
- Нет rate-limiting и защиты от локального злоупотребления — угроза считается доверенной (это тот же пользователь, что и в GUI).

## Как сообщить об уязвимости

Открыть [issue в этом репозитории](https://github.com/Deskezz-exe/ssh-mcp-client/issues) с пометкой `security`.

Это личный проект в разработке, ответ не гарантирован в конкретные сроки, но каждое сообщение будет прочитано.
